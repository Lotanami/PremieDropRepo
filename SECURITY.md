# Security Policy

PremieDrop is currently in beta. Please report security issues privately rather
than opening a public issue first.

## Supported Versions

The latest GitHub release is the only version expected to receive fixes.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting A Vulnerability

If you find a security issue, contact the repo owner through GitHub with:

- A short description of the issue.
- Steps to reproduce it.
- What files, downloads, or system areas are affected.
- Any logs or screenshots that help explain the problem.

Please do not post working exploit details publicly until there has been time
to investigate and fix the issue.

## Security-Sensitive Areas

Useful areas to review include:

- Download handling and URL validation.
- Installer behavior.
- Premiere Pro CEP extension install behavior.
- Local file access and drag/drop behavior.
- Browser cache and stored browser preset handling.
