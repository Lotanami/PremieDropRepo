# Support

PremieDrop is a beta project. Support is currently community-driven through
GitHub.

## Where To Get Help

- Use GitHub Issues for bugs, feature requests, and contributor questions.
- Use Pull Requests for proposed code or documentation changes.
- Include screenshots, logs, or short screen recordings when they help explain
  the problem.

## Before Opening An Issue

Please include:

- Your Windows version.
- PremieDrop version or installer version.
- Whether VLC Media Player is installed.
- Whether Premiere Pro is installed, if the issue involves the CEP bridge.
- Steps to reproduce the issue.
- What you expected to happen.
- What actually happened.

## Current Limitations

- PremieDrop is Windows-first right now.
- VLC Media Player is required separately for video preview playback.
- Premiere Pro CEP support is available, but UXP support is not implemented
  yet.
- Final Cut Pro, DaVinci Resolve free-version support, and macOS compatibility
  are future goals.
